# 🚀 Portfolio Web Premium Dark

Un portafolio web personal estéticamente diseñado bajo un concepto **Dark Premium Exclusivo**, pensado para desarrolladores y aprendices de programación que desean destacar su recorrido técnico, lenguajes aprendidos y avances.

---

## 🌟 Características Principales

- **Diseño Ultra Moderno:** Estética oscura con efecto *Glassmorphism* (cristal esmerilado) y luces ambientales *Neon Ambient Glow*.
- **Animaciones Interactivas:**
  - Animaciones de aparición suave al hacer scroll (*Scroll Reveal* mediante JavaScript e `IntersectionObserver`).
  - Movimiento dinámico parallax interactivo al mover el cursor sobre los efectos ambientales.
  - Efectos *hover* refinados en tarjetas y botones.
- **Secciones Clave Incluidas:**
  - **Sobre Mí / Hero:** Introducción concisa y profesional con botones de acción rápida.
  - **Lenguajes & Dominio:** Visualización de habilidades técnicas con barras de nivel.
  - **Línea de Tiempo de Aprendizaje:** Registro estructurado y cronológico del progreso como estudiante/aprendiz.
  - **Snippet Showcase:** Ventana interactiva tipo editor de código (VS Code style) para mostrar fragmentos de código real.
- **Responsivo:** Adaptado para una óptima lectura tanto en dispositivos móviles como en pantallas de escritorio.
